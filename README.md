# Placar Basquete — instaladores

Instalador Windows do placar eletrônico de basquete FIBA. O código vive em
`whenes/placar-basquete`; aqui só ficam os binários.

## Baixar

Pegue o `.exe` mais recente em [Releases](https://github.com/whenes/placar-basquete-releases/releases/latest).

O instalador não é assinado: o Windows mostra "editor desconhecido" na primeira
execução — em *Mais informações* → *Executar assim mesmo*.

## Como funciona

Cada tag `vX.Y.Z` no repo do código dispara o build no GitHub Actions, que publica
a release aqui. Só as 5 versões mais recentes ficam; as anteriores são removidas.
