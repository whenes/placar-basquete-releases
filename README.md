# Placar Esportivo

**[Baixar a versão mais recente para Windows](https://github.com/whenes/placar-basquete-releases/releases/latest)**

## Placar eletrônico para escolas, sem placar físico

O **Placar Esportivo** transforma um computador e uma TV ou monitor que a escola já tem em placar eletrônico de quadra. Serve para aulas de educação física, jogos internos, interclasses e campeonatos escolares — sem comprar placar de parede.

Funciona com duas telas:

- **Placar** — na TV ou monitor virado para a quadra, em tela cheia, com números grandes para leitura de longe.
- **Mesa de controle** — no notebook ou monitor do operador, com botões e atalhos de teclado para marcar pontos, faltas, tempos e parar o relógio.

Tudo o que é feito na mesa aparece na hora no placar. Não precisa de internet.

### Modalidades

| | Basquete | Futsal | Vôlei |
|---|---|---|---|
| Relógio | 4 períodos de 10 min | 2 tempos de 20 min | limite de set opcional |
| Pontos | +1, +2, +3 | +1 | +1, com sets automáticos |
| Extras | tempo de arremesso 24s/14s, faltas, bônus, posse | faltas e bônus | sets, timeouts e saque |

A duração dos tempos é ajustável (1 a 60 min), para aulas e jogos mais curtos.

### Do que você precisa

- Computador com **Windows 10 ou 11**.
- Uma **TV ou monitor** ligado ao computador (cabo HDMI, por exemplo). Com uma tela só também funciona, mas o ideal são duas: placar para o público e controle para o operador.

### Como instalar

1. Baixe o arquivo **`Placar-Esportivo-Setup-….exe`** na [última release](https://github.com/whenes/placar-basquete-releases/releases/latest), em *Assets*.
2. Abra o arquivo baixado. O instalador ainda não é assinado, então o Windows pode avisar "O Windows protegeu o computador": clique em **Mais informações** → **Executar assim mesmo**.
3. Ao abrir, escolha em qual tela fica o placar e qual é a modalidade. Pronto para o jogo.

### Atalhos principais

| Tecla | Ação |
|---|---|
| `Espaço` | inicia / pausa o relógio |
| `Q` / `O` | ponto para casa / visitante |
| `Z` / `M` | pedido de tempo casa / visitante |
| `B` | sirene |
| `Ctrl+Z` | desfaz o último comando |
